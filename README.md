# 🔊 Speaker Cleaner

A Flutter-based mobile application designed to help remove water and moisture from smartphone speakers using controlled audio frequency playback.

## ✨ Features

- 🔊 Multiple cleaning modes
- 💧 Water Eject mode
- ⚡ Quick Clean mode
- 🔥 Deep Clean mode
- 🎚️ Adjustable cleaning volume
- ⏱️ Countdown timer and progress tracking
- 🛑 Start and Stop controls
- 📖 First-launch onboarding
- ⚙️ Settings and safety information
- 🎨 Custom app icon and splash screen
- 📱 Responsive Flutter UI

## 🛠️ Tech Stack

- Flutter
- Dart
- audioplayers
- SharedPreferences

## 📱 Platform

- Android

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:ghaniashahzad01/Speaker-Cleaner-App.git
```
### 2. Navigate to the project
```
cd Speaker-Cleaner-App
```
### 3. Install dependencies
```
flutter pub get
```
### 4. Run the application
```
flutter run
```
